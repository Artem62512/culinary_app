🥗 Culinary App
Ваши рецепты — у вас

Планируйте блюда и покупки в одном месте

Создавайте рецепты, пересчитывайте ингредиенты на нужное число порций и собирайте список покупок с расчётом КБЖУ и стоимости.

Скачать ZIP для Windows Открыть проект на GitHub

В ZIP есть batch-файлы запуска frontend и backend. Для первого запуска нужны Python 3.14, Node.js 22 и установка зависимостей по инструкции в README. База SQLite хранится локально; для обновления цен и КБЖУ нужен интернет.

Что входит в ZIP

✓Отдельные BAT-файлы для backend и frontend
✓Общий запуск через Culinary App.bat
✓Первичная база SQLite создаётся локально
✓Пошаговая инструкция по настройке в README

Рецепты

Храните свои рецепты, сопоставляйте ингредиенты с каталогом и меняйте число порций.

КБЖУ

Смотрите расчёты по известным пищевым данным; отсутствующие значения не подменяются нулями.

Покупки

Собирайте корзину и учитывайте выбранные товары и цены магазинов.
